ServerFlow 服务器排班 __SHORT__
==========================

安装
----
双击 ServerFlow-Setup.exe，在 UAC 窗口点“是”，等几秒即完成。
不需要解压、不需要提前信任证书、不需要改系统设置。
安装器会自动完成：证书信任 → 应用安装 → 启动程序。

其他文件（可选，一般用不到）
- ServerFlow___VERSION___x64.msix
  应用安装包本体。证书已受信任时可直接双击，点“安装”。
- ServerFlow-Local.cer
  自签名测试证书，仅手动安装时需要。
- Install-ServerFlow.cmd
  命令行安装脚本，行为与安装器一致。

重要：不要双击 ServerFlow.appinstaller。
它是自动更新源配置文件，不是安装入口；双击会报
“Error in parsing the app package（无法解析安装包）”。

手动安装（命令行）：
- 以管理员身份运行：
  certutil.exe -f -addstore Root ServerFlow-Local.cer
- 再运行：
  Add-AppxPackage -Path .\ServerFlow___VERSION___x64.msix -ForceUpdateFromAnyVersion

更新
----
- 应用底部「检查更新」按钮读取 GitHub Releases 最新版本，并显示是否已是最新。
- 用 Install-ServerFlow.cmd 安装的机器还会注册 App Installer 更新源，
  系统会在启动时按 24 小时、后台约每 8 小时自动检查。
- 用 ServerFlow-Setup.exe 安装的机器不注册该系统更新源，请用应用内按钮更新；
  或直接运行新版安装器覆盖安装，排班数据会保留。
- 更新源位于仓库 raw 文件：
  https://raw.githubusercontent.com/royluobox/ServerFlow/main/tools/installer-template/ServerFlow.appinstaller
- 每个版本使用独立的 Release 资产地址，避免同名 CDN 缓存。

系统要求
--------
Windows 10 1809 或更高版本，x64。推荐 Windows 11。
应用包含 .NET 8 与 Windows App SDK 运行组件，无需另装运行库。
只有“证书尚未受信任”这一步需要管理员批准；证书受信任后，
安装、升级和运行都不需要管理员权限。

文件校验
--------
各文件 SHA256 见 SHA256SUMS.txt。
签名证书: CN=ServerFlow Local
证书指纹(SHA1): C16B8C5B509B82C3B679EAEE8309EA77437CCBD2
证书有效期至: 2029-11-04

使用
----
- 单击日期查看占用，点击“添加排班”。
- 支持单次、每天、每周重复，可设开始时间、时长和截止日期。
- “前台操作”表示有人值守；“后台运行”表示程序仅占用服务器资源。
- 备注可选，无需姓名或账号。
- 每个日期格左侧是 24 小时时间轴，占用按真实起止时间涂色；50 小时会占满中间整天，第三天只涂对应比例。
- 前台（蓝）与后台（青）互不冲突，可占用同一时段；同一使用方式之间仍会阻止重叠。
- 时间冲突会阻止保存，并提示冲突排班的完整区间；周期排班删除时会删除整条规则。
- 网络仅用于公开 HTTPS 校时、GitHub 版本检查和更新下载；不上传排班内容。
- 断网时使用本机时间，排班功能仍可完整使用。

数据位置
--------
%LOCALAPPDATA%\Packages\ServerFlow.Scheduler_pbhj1ej857fh2\LocalCache\Local\ServerFlow\schedules.json
卸载应用前如需保留数据，请先备份此文件。

卸载
----
Windows 设置 > 应用 > 安装的应用 > ServerFlow 服务器排班 > 卸载。
如需清理测试证书，以管理员身份运行 certlm.msc，
在“受信任的根证书颁发机构”中删除 CN=ServerFlow Local。

签名说明
--------
这是本地测试签名安装包，不是商业代码签名证书。
系统可能提示发布者未知；只安装来自可信 Release 且 SHA256 匹配的文件。
正式发布可替换为商业代码签名证书或改用 Microsoft Store 分发。
